HOW THESE APIS ARE CALLED
-------------------------
Both APIs are plain HTTPS GET/POST/... calls that answer JSON (or XML). A browser cannot call them directly (CORS),
and they expect the headers "Origin: https://speedhive.mylaps.com" and "Referer: https://speedhive.mylaps.com/".
Icesights therefore calls them through its Cloudflare Worker (cloudflare-worker/src/index.js), which adds those
headers and only exposes the seven read operations marked USED BY ICESIGHTS below.
The Swagger files declare an "Apikey" header for the whole API, and operations marked "needs a login" also require an
"Authorization" header with an access token of a MYLAPS account. The operations Icesights uses are public reads that
work with only the two headers above (checked against the live API); for every other operation the list only shows
what the Swagger file says, it has not been tried.
The name search that Icesights also uses (https://search.speedhive.com/api/search) belongs to a third service that has
no Swagger file here, so it is not in this list.

Legend:  {name} in an address is a value you fill in.  path/query/header/body = where a parameter goes.
